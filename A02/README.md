# A02 — P+7 (Oulipian language modelling)

A variation on the Oulipo's N+7 technique: the last word of each line of Wallace Stevens' *The Snow Man* is replaced with the word GPT-2 ranks x-th most probable at that position.

| File | Contents |
|---|---|
| `A02_P+x.ipynb` | Notebook that generates every version with GPT-2 (`openai-community/gpt2`) |
| `P+7.txt` | The poem processed with P+7 |
| `P+250.txt` | The poem processed with my chosen x (250) |
| `reflection.md` | Reflection on how x changes the output, and how to apply P+7 to every noun |
